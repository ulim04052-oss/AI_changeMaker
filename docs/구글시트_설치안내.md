# 구글 시트로 팀이 같이 쓰기: 설치 안내

화장품으로 비유하면 이렇게 나눠져 있어요.

- **구글 시트** = 창고예요. 제품, 일정, 메모가 표로 쌓여요.
- **Apps Script** = 창고 관리인이에요. 화면이 "가져와 줘", "넣어 줘" 하면 시트에 읽고 써요.
- **웹앱 주소** = 매장 입구예요. 팀원들은 이 주소 하나로 들어와서 같은 달력을 봐요.

처음 한 번만 하면 돼요. 15분쯤 걸려요.

## 준비물

- 회사 구글 계정 (@clio.co.kr)
- 파일 2개: `Code.gs`, `Index.html` (저장소의 `apps-script` 폴더 안에 있어요)

---

## 1단계. 구글 시트 만들기

1. 회사 계정으로 로그인한 상태에서 주소창에 `sheets.new` 를 치면 새 시트가 열려요.
2. 왼쪽 위 "제목 없는 스프레드시트"를 눌러서 이름을 **제품 일정 캘린더**로 바꿔요.

## 2단계. Apps Script 열기

1. 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
2. 새 탭이 열리고, `Code.gs` 파일에 `function myFunction() { }` 이 적혀 있어요.

## 3단계. 코드 붙여넣기 (2개)

**① Code.gs**

1. `Code.gs`의 내용을 전부 지워요 (Ctrl+A 누르고 Delete).
2. 받은 `Code.gs` 파일을 메모장으로 열어 전부 복사한 뒤 붙여넣어요.
3. 💾 저장 아이콘(또는 Ctrl+S)을 눌러요.

**② Index.html**

1. 왼쪽 "파일" 옆 **＋** 를 누르고 **HTML**을 골라요.
2. 이름은 꼭 **Index** 라고 적어요. 대문자 I이고 `.html`은 빼요.
3. 안에 있던 내용을 전부 지우고, 받은 `Index.html` 내용을 전부 붙여넣어요. 글이 아주 길어요. 정상이에요.
4. 저장해요.

## 4단계. 시트에 탭 만들기 (setup 한 번 실행)

1. 위쪽 ▶ 실행 버튼 옆의 함수 고르는 칸에서 **setup**을 골라요.
2. **▶ 실행**을 눌러요.
3. "승인 필요" 창이 뜨면 **권한 검토**를 누르고 회사 계정을 골라요.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요. 내가 만든 코드라서 괜찮아요.
   - **허용**을 눌러요.
4. 시트로 돌아가면 아래쪽에 탭 6개가 생겨 있어요: 제품 · 부자재 · 일정 · 이슈 메모 · 필요 일정 · 설정.

## 5단계. 웹앱으로 배포 (팀원 입구 만들기)

1. Apps Script 오른쪽 위 파란 **배포 → 새 배포**를 눌러요.
2. "유형 선택" 옆 ⚙ 톱니를 누르고 **웹 앱**을 골라요.
3. 아래처럼 채워요.
   - 설명: `1차` (아무거나 적어도 돼요)
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **clio.co.kr 내 모든 사용자**
4. **배포**를 누르면 **웹 앱 URL**이 나와요. 복사해 두세요.
5. 그 주소를 열어서 달력이 뜨면 성공이에요. 위쪽에 "✓ 구글 시트에 저장됨"이 보여요.

## 6단계. 팀원에게 공유

- 5단계에서 복사한 **웹 앱 URL만** 팀원에게 보내면 돼요.
- 회사 계정으로 로그인한 사람만 들어올 수 있어요. 회사 밖 사람은 못 들어와요.
- 시트 파일은 따로 공유하지 않아도 돼요. 시트를 표로 직접 보고 싶은 사람이 있으면 그 사람에게만 **보기 권한**으로 공유해 주세요.

---

## 화면이 바뀌었을 때 업데이트하는 법

화면을 고치면 `Index.html` 이 새로 만들어져요.

1. Apps Script의 `Index` 파일 내용을 전부 지우고 새 내용을 붙여넣은 뒤 저장해요. `Code.gs`가 바뀌었으면 그것도 똑같이 해요.
2. **배포 → 배포 관리** → 연필 ✏️ → 버전에서 **새 버전**을 고르고 → **배포**를 눌러요.
3. 주소는 그대로예요. 팀원은 새로고침만 하면 돼요.

## 알아 두면 좋은 것

- **두 사람이 동시에 고치면**: 먼저 저장한 사람 것이 남아요. 나중 사람 화면 위쪽에 "다른 팀원이 먼저 고쳤어요"가 떠요. 그 사람이 **최신 내용 불러오기**를 누르고 방금 고친 걸 한 번 더 하면 돼요.
- **시트에서 직접 고치지 마세요.** 시트는 보는 용도로만 써 주세요. 누가 화면을 열어 둔 채 저장하면, 시트에서 직접 고친 내용이 덮어써질 수 있어요.
- **잘못 지웠을 때**: 시트에서 **파일 → 버전 기록 → 버전 기록 보기**를 열면 예전 상태로 되돌릴 수 있어요.
- **누가 마지막에 저장했는지**: `설정` 탭의 "마지막 저장" 줄에 시간과 이메일이 남아요.
- 탭에서 `id`로 끝나는 칸은 서로를 이어 주는 번호라서 절대 바꾸면 안 돼요.
